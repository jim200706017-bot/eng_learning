# 英语秘书团 V1.0 — 使用指南

> English Butler: Your AI-powered English Learning Companion

---

## 一、概览

英语秘书团是一个由 **4 位 AI 秘书** 组成的英语学习系统，运行在 Claude Code 之上，帮你每天 30-60 分钟系统化提升英语。

### 你的秘书团队

| 角色 | 名字 | 职责 | 音色 |
|------|------|------|------|
| 🎯 主控调度 | **Victoria** | 每日学习规划、SRS 复习、进度追踪、周报 | 英音女声 (Sonia) |
| 📖 词汇管家 | **Edmund** | 多词典查词、词条构建、发音、词源 | 英音男声 (Ryan) |
| ☕ 口语伙伴 | **Charlie** | 三阶段口语练习、纠错、自由对话 | 美音女声 (Jenny) |
| 📰 新闻主播 | **Beatrice** | 外刊热点抓取、晨间简报、关键词提取 | 英音女声 (Libby) |

### 核心流程

```
每天早晨: Beatrice 简报 → 阅读 + 选词
   ↓
白天:     Edmund 查词 → TTS 发音 → 存入词库
   ↓
晚间:     Charlie 口语练习 → 纠错 → 反思记录
   ↓
持续:     Victoria SRS 复习 + 进度追踪
```

## 二、快速开始

### 首次启动

在项目目录打开 Claude Code：

```bash
cd C:\Users\HUAWEI\Desktop\AI工具\英语学习\V-1.0
claude
```

### 每日使用（建议顺序）

#### 步骤 1：获取今日简报

```
/beatrice
```

系统会自动：
- 用 WebSearch 从 **TechCrunch / Reuters / ABA Journal / BBC** 抓取最新新闻
- 生成结构化晨间简报（AI 科技 / 金融 / 法律 / 全球）
- 提取关键词并标注 CEFR 等级
- 保存到 `briefings/YYYY-MM-DD-briefing.md`

#### 步骤 2：阅读简报并挑选词汇

阅读简报内容，对你感兴趣的生词执行：

```
add liability
add precedent
add governance
```

Edmund 会自动：
- 查多源词典释义
- 构建结构化词条存入 `vocabulary/<word>.json`
- TTS 朗读发音
- 更新词汇索引和 SRS 复习计划

#### 步骤 3：口语练习

```
/charlie
```

Charlie 会根据今日简报话题和生词，与你进行三阶段口语练习：
- **Stage 1 (控制式)**: 提供句型框架，你填充内容
- **Stage 2 (引导式)**: 给定目标词汇，在对话中自然使用
- **Stage 3 (自由式)**: 自由对话，自然纠错

#### 步骤 4：SRS 复习

```
/victoria
```

Victoria 检查今日 SRS 复习队列，按间隔时间（1天→3天→7天→14天→30天→90天）推送复习。

## 四、功能详解

### 4.1 Beatrice — 新闻简报

**工作流程**：
1. 对 4 个类别（AI/金融/法律/全球）各搜索 2-3 篇最新文章
2. 用 Playwright 访问文章页面抓取内容和截图
3. 提取 5-8 个关键词并标注 CEFR 等级（A1-C2）
4. 生成结构化简报，包含词汇池

**关键词 CEFR 标注参考**：

| 等级 | 含义 | 示例 |
|------|------|------|
| A1-A2 | 基础 | algorithm, browser, startup |
| B1 | 中级 | discount, accuracy, predict |
| B2 | 中高级 | liability, equity, governance |
| C1 | 高级 | precedent, deceptive, valuation |
| C2 | 精通 | jurisprudence, jurisprudence |

**输出文件**：
- `briefings/YYYY-MM-DD-briefing.md` — 结构化简报
- `briefings/YYYY-MM-DD-sources.md` — 来源记录
- `briefings/daily-word-pool.json` — 今日词汇池（供 Victoria 读取）
- `briefings/screenshots/` — 网页截图缓存

### 4.2 Edmund — 词汇管家

**查词来源**（按优先级）：
1. Cambridge Dictionary — 英英释义
2. Oxford Dictionary — 学术释义
3. Collins COBUILD — 整句释义
4. Merriam-Webster — 美式拼写用法
5. Cornell LII / Wex — 法学术语（法律词激活）
6. 词源（Etymonline）— 词根词缀
7. 同义词 / 反义词

**词条结构** (`vocabulary/<word>.json`)：
```json
{
  "word": "tort",
  "phonetic": "/tɔːrt/",
  "definitions": [
    {"source": "Cambridge", "definition": "..."},
    {"source": "Oxford", "definition": "..."}
  ],
  "etymology": "Latin: tortus — twisted",
  "collocations": ["tort law", "tort reform"],
  "domain": "law",
  "cefr": "B2"
}
```

**TTS 发音**：支持 normal（正常语速）和 slow（慢速 -20%）

### 4.3 Charlie — 口语伙伴

**三阶段脚手架**：

| 阶段 | 适合场景 | 模式 |
|------|---------|------|
| Stage 1 | 新话题 / 信心不足 | Charlie 提供句型框架，你填充内容 |
| Stage 2 | 中等水平 | 给定 3-5 个目标词，半结构化讨论 |
| Stage 3 | 高级水平 | 完全自由对话，自然纠错 |

**纠错机制**（三层）：

| 层级 | 触发条件 | 方式 |
|------|---------|------|
| Level 1 | 严重语法错误 | 自然改述，不打断对话 |
| Level 2 | 同类错误重复出现 | 话轮结束后温和指出 |
| Level 3 | 对话结束 | `sessions/` 中统一总结 |

**会话记录**：每次对话自动保存到 `sessions/YYYY-MM-DD-charlie.md`，包含元认知反思（3 个问题）。

### 4.4 Victoria — 主控调度

**职责**：
- 每日学习计划编排
- SRS 间隔重复调度
- 学习进度追踪
- 周报生成

**SRS 复习间隔**：

| Stage | 间隔 | 说明 |
|-------|------|------|
| 0 | 1 天 | 新词初次复习 |
| 1 | 3 天 | 短期记忆巩固 |
| 2 | 7 天 | 一周回顾 |
| 3 | 14 天 | 双周巩固 |
| 4 | 30 天 | 月度复习 |
| 5 | 90 天 | 长期记忆，可标记 productive |

## 八、注意事项

1. **首次使用**：确保 Playwright MCP 可用（已配置在 `settings.local.json`）
2. **TTS 发音**：需要网络连接（edge-tts 调用微软 Azure TTS）
3. **新闻时效**：WebSearch 抓取的是近期热点，已按你的兴趣分类（AI > 金融 > 法律 > 全球）
4. **口语练习**：实际对话时 Charlie 会等你回应，请用英文完整句子回答
5. **学习节奏**：每天 30-60 分钟即可，关键是持续，不要中断
6. **SRS 系统**：每天先复习旧词再学新词，复习比学新词更重要
