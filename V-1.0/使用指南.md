# English Secretary V2.0 — User Guide

> English Butler: Think in English. Work in English.

---

## 1. Overview

English Secretary is an AI-powered English learning system with **4 AI agents**, running on Claude Code + Web UI.

### Your Secretary Team

| Role | Name | Duty | Voice |
|------|------|------|-------|
| Director | **Victoria** | Daily planning, SRS review, progress tracking | British female (Sonia) |
| Vocabulary | **Edmund** | Multi-dictionary lookup, JSON entries, etymology | British male (Ryan) |
| Speaking | **Charlie** | 3-stage speaking scaffolding, error correction | US female (Jenny) |
| News | **Beatrice** | Foreign press scraping, morning briefing, keywords | British female (Libby) |

### Core Flow

```
Morning: Beatrice briefing → Read + Select words
   ↓
Daytime: Edmund lookups → Save to vocabulary library
   ↓
Evening: Charlie speaking practice → Error correction → Reflection
   ↓
Ongoing: Victoria SRS review + Progress tracking
```

## 2. Quick Start

### Using Claude Code (CLI)

```bash
cd C:\Users\HUAWEI\Desktop\AI工具\英语学习\V-1.0
claude
```

### Using Web UI (Browser)

```bash
cd web
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

Open http://localhost:8000

Web UI features:
- Gmail-style sidebar to switch agents
- Voice input (microphone button)
- Auto speech output for responses
- Real-time vocabulary library viewer
- Today's briefing viewer
- Learning stats dashboard

### Daily Routine (Recommended)

#### Step 1: Get Today's Briefing
```
/beatrice
```
Or click Beatrice in Web UI.

#### Step 2: Read & Select Words
Read the briefing, look up words:
```
add liability
add precedent
```

#### Step 3: Speaking Practice
```
/charlie
```

#### Step 4: SRS Review
```
/victoria
```

## 3. Commands

| Command | Action |
|---------|--------|
| `/beatrice` | Generate morning briefing |
| `add <word>` | Look up word, save to vocabulary |
| `/charlie` | Start speaking practice |
| `/victoria` | Main panel, SRS review |
| `stats` | View learning statistics |
| `review` | View SRS review queue |
| `vocab list` | List all learned words |

## 4. Data Files

| Directory | Purpose | Key Files |
|-----------|---------|-----------|
| `vocabulary/` | Vocabulary library | `index.json`, `<word>.json`, `README.md` (auto view) |
| `briefings/` | Morning briefings | `YYYY-MM-DD-briefing.md`, `daily-word-pool.json` |

| `prepare/` | Exam prep | `cet4-28day-plan-*.json` |
| `mcp/` | MCP servers | `edge_tts_server.py` |

## 5. Vocabulary Library Viewer

The vocabulary library is auto-generated at `vocabulary/README.md`.

Regenerate it anytime:
```bash
python vocabulary/vocab-view.py
```

Or view it live in the Web UI by clicking the 📖 button.

## 8. Notes

1. **Full English environment**: All agents operate in English only
2. **Web UI**: Requires Python 3.11+. Voice input needs Chrome browser.
3. **TTS**: Web UI uses browser Speech Synthesis (no edge-tts needed for voice output)
4. **Edmund voice guide removed**: No auto-TTS on word lookup
5. **Consistency**: 30-60min daily. Review > new words.
