# 英语秘书团 V2.0 — 技术架构（小白友好版）

> 如果你不懂编程，没关系。这份文档用大白话告诉你这个系统是怎么工作的。

---

## 一、一句话说清楚

**英语秘书团 = 4个AI英语老师 + 1个网页 + 你的本地文件夹**

它们帮你每天读英语新闻、查单词、练口语、复习，全英文沉浸式学习。

## 三、4位秘书的分工（用生活比喻）

### 🎯 Victoria（维多利亚）— 你的学习总指挥

**像你的私人学习教练。** 她负责：
- 每天早上跟你说今天要学什么
- 安排复习计划（哪些词该复习了）
- 催你完成学习目标
- 每周给你出学习报告

> 你找她：`/victoria` 或在网页左侧点 Victoria

### 📖 Edmund（埃德蒙）— 你的活字典

**像一本会说话的牛津词典。** 他负责：
- 你遇到生词，他帮你查 7 本词典
- 把单词的所有信息存成 JSON 文件
- 告诉你词源故事（这个词从哪来的）
- 特别擅长法律英语词汇

> 你找她：`add liability` 或聊天框输入

### ☕ Charlie（查理）— 你的口语陪练

**像你的一位美国朋友。** 她负责：
- 跟你用英语聊天
- 根据你的水平调整难度（简单→中等→自由聊）
- 你犯错时自然纠正，不打断对话
- 聊完帮你总结哪里该改进

> 你找她：`/charlie` 或在网页左侧点 Charlie

### 📰 Beatrice（碧翠丝）— 你的新闻主播

**像 BBC 新闻播音员。** 她负责：
- 每天早上从 16 个外媒抓取最新新闻
- 生成英文简报（AI/金融/法律/全球）
- 提取关键词，标注难度等级
- 推荐的词你可以一键查词学习

> 你找她：`/beatrice` 或在网页左侧点 Beatrice

## 四、每天的学习流程

```
早晨  🌅
  1. Beatrice 生成今日简报（自动）
  2. 你读简报，圈出生词
  3. 对生词说 "add xxx" 查词

白天  ☀️
  4. Edmund 查词，存入库
  5. 你随时可以查看词汇库

晚上  🌙
  6. Charlie 陪你练口语（用今天学的词）
  7. Victoria 安排复习今天学的词

持续  🔄
  8. SRS 复习系统：1天→3天→7天→16天→35天→90天
  9. 周日 Victoria 出周报
```

## 五、文件都放在哪（你的数据）

你电脑上的文件夹结构：

```
V-1.0/                          ← 项目根目录
├── vocabulary/                 ← 📚 你的词汇库（最重要！）
│   ├── index.json              ← 词汇总表
│   ├── tort.json               ← 每个词一个文件
│   └── README.md               ← 自动生成的词库一览表
├── briefings/                  ← 📰 每日简报
│   └── 2026-05-16-briefing.md
├── sessions/                   ← 💬 口语练习记录
├── review/                     ← 🔄 复习计划
├── stats/                      ← 📊 学习统计
├── web/                        ← 🌐 网页版（双击就能用）
│   ├── app.py                  ← 后端程序
│   └── static/                 ← 前端页面
└── config/                     ← ⚙️ 你的个人配置
    └── user-profile.json       ← 你的画像（法学生、CET-4等）
```

### 不用记路径，记住这几点就行：
- **查过的词** → 都在 `vocabulary/` 里
- **今天的新闻** → 在 `briefings/` 里
- **聊天记录** → 在 `sessions/` 里
- **学习进度** → 在 `stats/` 里

## 六、技术原理（一句话版）

| 技术 | 用来做什么 | 简单理解 |
|------|-----------|---------|
| Claude Code | 运行AI秘书的"大脑" | 像微信里跟AI聊天 |
| DeepSeek API | 大模型驱动对话 | 秘书们的"智商"来源 |
| FastAPI + Uvicorn | 网页后台 | 让浏览器能跟AI说话 |
| Web Speech API | 语音输入输出 | 浏览器自带的语音功能 |
| edge-tts | 朗读单词（Claude端用） | AI帮你读单词 |
| browser-search | 浏览器自动搜新闻 | 机器人帮你上网看新闻 |
| Playwright | 控制浏览器 | 自动打开网页截图 |
| JSON文件 | 存你的学习数据 | 像Excel表格存你的词库 |

## 七、两种使用方式对比

| 对比项 | Claude Code 终端 | Web 网页 |
|--------|-----------------|----------|
| 怎么打开 | 终端输入 `claude` | 浏览器打开 `localhost:8000` |
| 适合谁 | 习惯打命令的人 | 习惯点鼠标的人 |
| 语音 | 只有TTS朗读 | 🎤 语音输入 + 🔊 语音输出 |
| 查词 | `add tort` 快捷 | 聊天框输入 |
| 看词库 | `python vocab-view.py` | 点 📖 按钮 |
| 看简报 | `/beatrice` | 点 📰 按钮 |
| 需要安装 | Claude Code | Python + 浏览器 |

## 八、常见疑问

**Q: 我不懂编程能用吗？**
A: 能。网页版只需要双击运行，然后浏览器打开就行。

**Q: 数据安全吗？**
A: 所有数据都存在你本地电脑，没有上传到任何服务器。只有AI对话会通过API发送。

**Q: 每天要学多久？**
A: 建议 30-60 分钟。关键是每天坚持。

**Q: 支持手机吗？**
A: 网页版可以在手机浏览器上打开，但语音功能最好用电脑Chrome。
