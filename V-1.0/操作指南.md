## 二、启动系统

### 方式 A：打开网页版（推荐，适合日常使用）

**第一步：启动后台**

在项目目录下运行：

```bash
cd web
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

你会看到：
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

**第二步：打开浏览器**

在 Chrome 地址栏输入：
```
http://localhost:8000
```

**搞定！** 你会看到 Gmail 风格的界面。

### 方式 B：打开 Claude Code（适合打命令）

在项目目录输入：
```bash
claude
```

## 五、词汇库操作详解

### 查词流程

当你读新闻遇到生词时：

```
你: add jurisdiction
```

系统自动：
1. ✅ 查询 7 部词典的释义
2. ✅ 生成结构化的词条 JSON
3. ✅ 存入词汇库
4. ✅ 更新复习计划

### 查看词汇库

**网页版：** 点击顶部 📖 按钮

**终端版：**
```bash
python vocabulary/vocab-view.py
```

你会看到：
```
# Vocabulary Library
| # | Word | Domain | CEFR | Status | SRS Stage | Next Review |
|---|------|--------|------|--------|-----------|-------------|
| 1 | tort | law | B2 | receptive | 0 | 2026-05-17 |
| 2 | liability | law | B2 | receptive | 0 | 2026-05-18 |
```

### 词汇状态说明

| 状态 | 含义 | 条件 |
|------|------|------|
| receptive | 刚学，能认出 | 默认状态 |
| productive | 已掌握，能主动使用 | 被 Charlie 激活 ≥2 次 |

## 六、SRS 复习系统

### 什么是 SRS？

SRS（间隔重复系统）是一种科学记忆方法：**在快忘记的时候提醒你复习**。

### 复习间隔

| 阶段 | 间隔 | 说明 |
|------|------|------|
| 0 | 1天 | 刚学 → 明天复习 |
| 1 | 3天 | 第一次复习通过 |
| 2 | 7天 | 一周回顾 |
| 3 | 16天 | 双周巩固 |
| 4 | 35天 | 月度复习 |
| 5 | 90天 | 已掌握，只需偶尔看 |

### 复习规则
- ✅ 答对 → 进入下一阶段，间隔延长
- ❌ 答错 → 回到阶段 1，缩短间隔

## 八、常见问题

### Q: 网页打不开？
确保先运行了 `python -m uvicorn app:app --host 0.0.0.0 --port 8000`，然后在浏览器输入 `http://localhost:8000`

### Q: 语音按钮不好用？
- 请使用 Chrome 浏览器
- 检查麦克风权限是否开启
- 确保网页是 HTTPS 或 localhost

### Q: 查词没反应？
- 检查网络连接
- DeepSeek API 可能暂时不可用

### Q: 词汇库文件在哪？
所有词汇存在 `vocabulary/` 文件夹，每个词一个 `.json` 文件

### Q: 怎么备份我的学习数据？
直接把整个 `V-1.0/` 文件夹复制一份就行，所有数据都在里面。推荐同步到 GitHub。
