## 二、你需要准备的东西

### 2.1 Skill 文件（核心，必须）

| 项目      | 说明                                  |
| ------- | ----------------------------------- |
| **文件**  | `~/.claude/skills/english-tutor.md` |
| **作用**  | 定义 Agent 的人格、能力、行为规范、数据读写规则         |
| **复杂度** | 纯 Markdown，约 150-200 行              |

Skill 文件包含两大模块的完整指令：

- **Word Library 模块**: 如何接收新词 → 如何查词典 → 如何写入 JSON → 如何触发 SRS
- **Speaking Practice 模块**: 如何加载词汇库 → 如何选择话题 → 如何纠错 → 如何写反思

**你不需要写代码，Skill 就是一个精心编写的提示词文件。**

***

### 2.2 TTS MCP Server（发音，必须）

| 项目      | 说明                                              |
| ------- | ----------------------------------------------- |
| **技术栈** | Python + `edge-tts` 库                           |
| **作用**  | 将文本转为自然语音，支持英音(UK)和美音(US)                       |
| **安装**  | `pip install edge-tts`，然后注册为 MCP Server         |
| **费用**  | 免费（使用 Microsoft Edge 公开 TTS 服务）                 |
| **音色**  | 英音: `en-GB-SoniaNeural`，美音: `en-US-JennyNeural` |

**MCP Server 暴露的工具**:

```json
{
  "tool": "speak",
  "parameters": {
    "text": "meticulous",
    "accent": "uk",        // "uk" | "us"
    "speed": "normal"       // "slow" | "normal"
  }
}
```

**为什么用 edge-tts 而不是系统 TTS**:

- Windows 自带 TTS 音色机械，学习者无法获得准确的发音模型
- edge-tts 使用微软神经网络语音，音色接近真人
- 免费且无需 API Key

## 四、MCP Server 详细配置

### 4.1 TTS MCP Server（edge-tts）

在 `settings.json` 中注册：

```json
{
  "mcpServers": {
    "edge-tts": {
      "command": "python",
      "args": ["-m", "edge_tts_mcp"],
      "env": {}
    }
  }
}
```

如果社区没有现成的 edge-tts MCP Server，需要自己写一个极简版（约 40 行 Python）。核心代码：

```python
# edge_tts_mcp.py — 最简实现
import asyncio
import edge_tts
import tempfile
import subprocess

VOICES = {
    "uk": "en-GB-SoniaNeural",
    "us": "en-US-JennyNeural"
}

async def speak(text: str, accent: str = "uk", speed: str = "normal"):
    voice = VOICES.get(accent, VOICES["uk"])
    rate = "-20%" if speed == "slow" else "+0%"
    communicate = edge_tts.Communicate(text, voice, rate=rate)
    with tempfile.NamedTemporaryFile(suffix=".mp3", delete=False) as f:
        await communicate.save(f.name)
    subprocess.run(["powershell", "-c", f"Start-Process '{f.name}'"])
```

### 4.2 是否需要词典 MCP Server？

**结论：不需要。** Claude Code 内置的 `WebFetch` 工具已足够。

理由：

- Cambridge、Oxford、Cornell LII 都是静态网页，WebFetch 可以抓取
- Agent 的 LLM 本身具备解析词典页面并结构化提取信息的能力
- 单独建一个词典 MCP Server 增加维护成本，收益很小

但如果后续需要批量导入大量词汇（50+ 词/天），可以考虑建一个词典聚合 MCP Server 来加速。
